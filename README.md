## ✨ О проекте

**World of Code** — это учебный проект, представляющий собой онлайн-платформу для практики решения задач по программированию. Пользователи могут выбирать задачи, писать код прямо в браузере и проверять его корректность.

**Основные функции:**
*   📚 **Каталог задач** по разным темам и сложности.
*   💻 **Встроенный редактор кода** с подсветкой синтаксиса для нескольких языков.
*   ⚡ **Мгновенная проверка** решений на предоставленных тестовых случаях.
*   🏆 **Система рейтинга** и достижений (в разработке).

## 🛠 Стек технологий

*   **Бэкенд:** [Python](https://www.python.org/) + [Flask](https://flask.palletsprojects.com/)
*   **Фронтенд:** HTML, CSS, JavaScript
*   **База данных:** [SQLite](https://www.sqlite.org/)
*   **Иконки:** [FontAwesome](https://fontawesome.com/)
*   **Стили:** [Bootstrap](https://getbootstrap.com/) (используется через CDN)

## 🚀 Быстрый старт

Эти инструкции помогут вам запустить копию проекта на вашей локальной машине для разработки и тестирования.

### Предварительные требования

1.  Убедитесь, что на вашем компьютере установлен **Python 3.8** или выше.
2.  Установите **Git**.

### Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/7emerys/WORLD-of-CODE.git
    cd WORLD-of-CODE
    ```

2.  **Создайте и активируйте виртуальное окружение (рекомендуется):**
    ```bash
    # Для Linux/macOS:
    python3 -m venv venv
    source venv/bin/activate

    # Для Windows:
    python -m venv venv
    .\venv\Scripts\activate
    ```

3.  **Установите необходимые зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Запустите приложение:**
    ```bash
    python run.py
    ```
    Или, если файл `run.py` не исполняемый:
    ```bash
    flask --app app run --debug
    ```

5.  **Откройте браузер!**
    Сервер запустится по адресу `http://localhost:5000`.
    Перейдите по этой ссылке, чтобы начать пользоваться приложением.

**Важно:** При первом запуске будет создана и инициализирована база данных SQLite (`instance/site.db`).

## 🧪 Как это работает

1.  **Просмотр задач:** Перейдите на вкладку "Задачи", чтобы увидеть список всех доступных проблем.
2.  **Выбор задачи:** Нажмите на задачу, чтобы увидеть ее подробное условие, примеры входных и выходных данных.
3.  **Написание решения:** Введите ваш код на одном из поддерживаемых языков в текстовое поле.
4.  **Проверка:** Нажмите кнопку "Проверить решение". Ваш код будет запущен на тестовых примерах, и вы сразу увидите результат (Успех или Ошибка).

**Поддерживаемые языки:** Python, C++, Java, JavaScript.
